# 🚀 Contador de Inscrições - PROA

Projeto desenvolvido como parte do programa **Transforme-se (Serasa Experian)** em parceria com o **Instituto PROA**, focado na prática de fundamentos de desenvolvimento web, manipulação do DOM e lógica com JavaScript.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout e responsividade.
- **JavaScript (ES6)**: Lógica de contagem e manipulação dinâmica dos elementos da página.

---

## 📌 Funcionalidades

- [x] **Contagem Dinâmica**: Incremento dos inscritos em tempo real ao clicar no botão.
- [x] **Regra de Vagas**: Validação para limitar o número de inscrições de acordo com as vagas disponíveis.
- [x] **Interface Interativa**: Visual moderno e responsivo para o usuário.
